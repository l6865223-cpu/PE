# Pikmin Bloom Threads 資訊收集 (PE 專案)

此專案用於收集與整理來自 **Threads (脆)** 上關於 **Pikmin Bloom (皮克敏 Bloom)** 的中文玩家發文資訊，主要聚焦於：
1. **當月活動資訊**（社群日、花朵盛開預告、特殊活動、菇類挑戰等）
2. **下個月預告與情報**（官方預告、玩家情報、解包/活動預測等）

## 目錄結構
- `current_month.md`：當月皮克敏活動與 Threads 整理資訊
- `next_month.md`：下個月皮克敏預告與情報
- `collector.py`：協助整理與記錄資訊的輔助腳本
